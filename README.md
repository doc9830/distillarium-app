# distillarium-app

Android-приложение «Дистиллярий»: вики, справочник, калькуляторы, партии и
рецепты. Офлайн-первый: весь контент лежит на устройстве, сеть нужна только
для обновления контента.

**Лицензия:** source available, см. [`LICENSE`](LICENSE). Код открытым
исходным не является.

## Структура

```
app/                 UI: Kotlin, Jetpack Compose, Material 3, навигация
core/content/        загрузчик пакета, проверка sha256, атомарная подмена, откат
core/data/           Room: партии, замеры, заметки, избранное; DataStore: настройки
assets/              встроенный content-pack.zip (появится в M0)
.github/workflows/   сборка APK и тесты (появятся вместе с Gradle-каркасом)
```

Границы модулей — по `docs/07`, §1 и `docs/09`, M0. `core/content` не знает
о UI и о `user.db`; `core/data` не знает о сети и файлах контента.

## Стек

| Слой | Решение |
| --- | --- |
| Язык и UI | Kotlin + Jetpack Compose, Material 3 |
| Хранение | Room (SQLite) + FTS5 |
| Настройки | DataStore |
| Обновления | WorkManager + OkHttp |
| Markdown | CommonMark + собственный рендер на Compose |
| Графики | Compose Canvas |
| minSdk / targetSdk | 26 / актуальный |

Версия приложения: `versionName` в `x.y.z`, `minAppVersion` пакета контента
сравнивается именно с ней.

## Что нельзя нарушать

1. Обновление контента пишет **только** в `files/content/`,
   `files/installed.json` и `databases/search.db`. В `user.db` — никогда.
2. Любая ошибка скачивания, распаковки или проверки оставляет текущий пакет
   нетронутым. Приложение продолжает работать офлайн.
3. Контент не выполняет код: только Markdown и JSON.
4. Пакет новее `schemaVersion` приложения не ставится.
5. `minAppVersion` больше версии приложения — пакет не ставится, показывается
   предложение обновить приложение.

## Команды

Появятся вместе с Gradle-каркасом в M0:

```bash
./gradlew :app:assembleDebug
./gradlew test
```

До этого в репозитории нет исполняемого кода — только структура и лицензия.
