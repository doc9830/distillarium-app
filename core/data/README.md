# core/data

Место для пользовательских данных: Room (`user.db`) и FTS5 (`search.db`),
настройки на DataStore.

В M0 здесь намеренно нет кода. Партий, замеров и `user.db` ещё нет, поэтому
Room-модуль с пустыми сущностями только добавил бы зависимости и миграции без
задачи. Конвейер контента живёт в `core/content` и не имеет доступа к этому
модулю; `user.db` не должен открываться при обновлении контента.

Порядок появления:

- M1 — `search.db`, FTS5 и перенос `search/index.json`;
- M3 — `user.db`: партии, журнал, замеры, рецепты;
- M5 — экспорт/импорт и настройки.
