# core/data

Модуль пока пуст: единственная пользовательская база `user.db` живёт в
`app/batches` на `SQLiteOpenHelper`. Для одной базы без общих JVM-потребителей
Room-модуль добавил бы только зависимости и миграции, а FTS5 не нужен: поиск
идёт по `search/index.json` из контент-пакета и загружается в память.

`user.db` не должен открываться при обновлении контента; конвейер живёт в
`core/content` и не имеет доступа к этому модулю.

Порядок появления:

- M1 — сделано без отдельной базы: `search/index.json` читается в память;
- M3 — сделано в `app/batches`: партии, шаги, замеры и журнал в `user.db`;
- M5 — экспорт/импорт и настройки; при необходимости модуль станет общей точкой.
