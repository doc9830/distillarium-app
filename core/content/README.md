# core/content

Чистый Kotlin/JVM-модуль конвейера контента. Не зависит от Android, поэтому
его тесты идут без эмулятора, а логику можно проверить на любой JVM.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `Manifest.kt` | разбор и базовая проверка `manifest.json` |
| `InstalledState.kt` | `installed.json` и состояние `current/previous` |
| `PackageValidator.kt` | файлы, sha256, id, `[[ссылки]]`, редиректы, медиа, индекс |
| `SafeZip.kt` | распаковка с защитой от zip-slip и лимитом объёма |
| `ContentInstaller.kt` | установка, атомарная подмена, откат, восстановление |
| `ContentUpdater.kt` | манифест → версия → скачивание → установка |
| `Sha256.kt`, `VersionNumbers.kt`, `SafePath.kt` | примитивы без зависимостей |

Точка входа для приложения — `ContentInstaller` и `ContentUpdater`. Сетевые
интерфейсы (`ManifestFetcher`, `PackDownloader`) и `EtagStore` подставляются
снаружи: модуль не знает об OkHttp, WorkManager и Android.

## Инварианты

- `current` заменяется только после полной проверки распакованного пакета.
- При ошибке на любом шаге `current` остаётся прежним; временные каталоги
  удаляются.
- `previous` хранится один; откат обратим, потому что бывший `current`
  становится `previous`.
- Пути с `..`, абсолютные пути, обратные слэши и управляющие символы
  отвергаются до записи.
- `databases/user.db` не открывается и не изменяется.

## Тесты

```bash
./gradlew :core:content:test
```

Покрыты: первый запуск, идемпотентность, обновление, откат, `user.db`,
битый архив, битая ссылка, zip-slip, новая схема, новый `minAppVersion`,
обрыв обновления и отката.
